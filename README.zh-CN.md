# clear-for-agents

指导 agent 撰写供其他 agent 使用的内容，只补充接收方完成任务所需的信息。

起因很简单：恢复一个任务未变、上下文仍在的会话，通常只需要一句 `continue`，agent 却经常附上任务复述、进度总结和各种提醒。这些文字会分散注意力，甚至改变原本清楚的任务。

同样的问题也出现在 subagent 提示词、review 委派、研究任务和仓库文档里。这个 skill 用一个问题判断文字是否值得保留：

> 删掉它，接收方会缺少什么必要信息，或在哪个具体判断上出错？

## 适用范围

提示词、subagent 任务、会话恢复与交接、skill、工具描述和参考文档。临时消息与持久化文件都适用，也包括人类与 agent 共用的内容。

它着重约束几种容易添乱的写法：

- **重复上下文**：省略接收方已经知道的要求、常识和默认就会执行的步骤。恢复同一任务时，默认只发 `continue`。
- **预设审查重点**：独立 review 按任务范围展开，由 reviewer 根据检查结果决定重点。
- **限制研究方向**：联网 research 保留问题、真实约束和必要背景，让检索证据引导方向。
- **把过程写进文档**：中间状态留在会话或必要交接中；仓库文档就地更新当前结论，过程记录沿用项目已有机制。

对共用文档，保留原有用途和组织方式，修改范围限于当前任务涉及的内容。

## 安装与使用

通过 [skills CLI](https://github.com/vercel-labs/skills) 从 GitHub 安装：

```sh
npx skills add Victor-Quqi/clear-for-agents -g
```

按提示选择目标 agent。`-g` 表示全局安装，供多个项目使用；省略后安装到当前项目。

安装后，支持自动选择 skill 的环境会根据任务匹配。也可以按所用环境的语法，通过 `/clear-for-agents` 或 `$clear-for-agents` 显式调用。

具体规则见 [SKILL.md](SKILL.md)。
